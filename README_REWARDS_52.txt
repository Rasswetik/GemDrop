GemDrop 52 — Награды и задания

Раздел «Розыгрыши» в нижнем меню переименован в «Награды».
При входе открывается вкладка «Задания»; рядом вкладка «Розыгрыши».

Админ-панель → «Задания и билеты»: создание заданий, настройка группы,
проверяемого условия, числа действий, награды в билетах, времени действия,
перехода и режима демонстрации. Задания можно включать и выключать.
Учитываются действия, произошедшие после создания задания. Ежедневные
задания обновляются по UTC. Демонстрационные карточки помечены как примеры
и не начисляют билеты. Стартовые реальные задания работают по данным
апгрейдов, пополнений и рефералов. Начисления выполняет сервер однократно
за период и записывает в ticket_ledger.

Для Fragment видео извлекается из JSON, Telegram и страницы Fragment.
Если источник не публикует видео, в форме добавления Fragment подарка
можно указать прямую HTTPS-ссылку на видео. При ошибке видео PNG остаётся
видимым; на устройствах с reduced motion анимация не запускается.

Обновление существующей базы выполняется при запуске; данные розыгрышей
сохраняются. Для запуска установите зависимости из requirements.txt.
