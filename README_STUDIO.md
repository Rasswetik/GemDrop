- Задания на недоступные режимы явно отмечены; уже выполненную награду можно получить. Крафт остаётся выведенным из продукта, Roll остаётся вне основной навигации.
- Добавлены управление диалогами с клавиатуры, возврат фокуса, обозначения клеток и текущего раздела.
- Методы Telegram вызываются только в поддерживающей их версии клиента. После сбоя загрузки TON Connect возможна повторная загрузка.

## Проверка

Из папки проекта:

```powershell
python -m unittest discover -s tests -v
```

17 интеграционных тестов: подпись Telegram и одноразовый вход, валидация запросов и ставок, выигрыш/проигрыш и восстановление Mines, блокировка режимов, повторный перевод и апгрейд, однократная продажа и награда, права на инвентарь, закрытие SQLite и откат транзакции. Тесты используют отдельную временную SQLite-базу и тестовые записи; реальные деньги и сообщения не используются.

Дополнительно проверены 49 GET-маршрутов API без ошибок 500, синтаксис JavaScript и Python, отсутствие повторяющихся HTML id и недостающих статических ссылок на элементы. В браузере проверены основные разделы, закрытие диалогов, экран входа и мобильные размеры 320 и 390 пикселей.

## Запуск и внешние сервисы

Зависимости не изменены. Обычный локальный запуск: `python app.py`. Для боевого запуска используются прежние настройки сервера и переменные окружения: `BOT_TOKEN`, `WEBAPP_URL`, `SECRET_KEY`, при необходимости `DATABASE_URL`, TON и Portal.

В переданной папке отсутствуют рабочая база, каталог подарков и конфигурация внешних сервисов. Реальная авторизация через Telegram, подтверждение TON-платежей, импорт Portal, отправка постов и работа PostgreSQL требуют проверки в настроенном окружении. Локальные тесты не подтверждают эти внешние интеграции. Обновление не публиковалось на удалённый сервер.

Основные изменённые файлы: `app.py`, `templates/index.html`, новый `static/css/gemdrop-studio.css`, `tests/test_regressions.py`. Старые таблицы стилей сохранены для совместимости сложных административных и игровых компонентов; новый слой подключён последним.
