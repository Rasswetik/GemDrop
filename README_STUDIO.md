## Исправления

- SQLite-соединения закрываются после выхода из контекста; транзакции сохраняют commit/rollback.
- API отклоняет повреждённый JSON и значения неправильного типа, вместо ошибки 500.
- Денежные значения проверяются на переполнение диапазона базы данных.
- Отключение розыгрышей действует и на список, и на отдельный розыгрыш. Начатый раунд Mines можно закончить после отключения режима.
- Настройки разделов принимают настоящие логические значения; повреждённые сохранённые настройки восстанавливаются к значениям по умолчанию.
- Сетевой тайм-аут включает загрузку тела ответа. Некорректный ответ сервера больше не считается успешным.
- При ошибке входа нельзя скопировать заглушку вместо кода; скрывается устаревшая ссылка на бота.
- После повторного входа правильно выбирается стартовый раздел.
- Кнопки заданий на депозит и приглашение ведут к нужному действию.
- Задания на недоступные режимы явно отмечены; уже выполненную награду можно получить. Крафт остаётся выведенным из продукта, Roll остаётся вне основной навигации.
- Добавлены управление диалогами с клавиатуры, возврат фокуса, обозначения клеток и текущего раздела.
- Методы Telegram вызываются только в поддерживающей их версии клиента. После сбоя загрузки TON Connect возможна повторная загрузка.
