# GemDrop · обновление 16

## Установка

1. Замените `app.py`, `templates/index.html` и папку `static/css/` файлами из архива. Новый `gemdrop-base.css` тоже обязателен.
2. Сохраните существующие переменные окружения, базу данных и каталог `DATA_DIR`. Токены и пароли менять не нужно.
3. Перезапустите приложение и заново откройте Mini App. При необходимости обновите страницу без кэша.

Изменения используют существующую таблицу `app_documents`; отдельная миграция не нужна. Для сохранности после перезапуска хостинга используйте существующую PostgreSQL либо постоянный диск для `DATA_DIR`. Временная файловая система хостинга не сохраняет SQLite между пересозданиями контейнера.

## Оформление

Обновлены основные игровые экраны, профиль, карточки игроков и страница управления игроком, публикации, админ-панель, бонусы, окна перевода, пополнения, подарков и наград. Единые тёмно-синие поверхности, светло-голубые акценты, компактные кнопки и навигация. Исправлены контуры и пропорции иконок подарков, билетов и переводов. Цвета редкости подарков сохранены.

## Приветствие

Админ-панель → Настройки бота → Приветствие после `/start` → Сохранить.

Поддерживаются Telegram HTML и `[emoji:ID:⭐]`. `{referral_percent}` заменяется актуальным процентом реферальной программы. Пустое поле возвращает исходное приветствие. Кнопки игры и инструменты администратора добавляются отдельно и не зависят от текста.

## Определение ID

Администратор отправляет `/start`, нажимает «Определить ID эмодзи» и присылает premium emoji, сообщение с ними, фото с подписью либо custom emoji стикер. Бот возвращает копируемые ID и кнопку «Определить ещё». Также доступна команда `/emoji`; `/cancel` завершает режим. Обычным пользователям эти инструменты недоступны.

ID сохраняются в базе отдельными записями без срока действия. Они доступны в Админ-панели → Публикации → Сохранённые эмодзи → Обновить. Поддерживаются ID длиннее безопасного целого JavaScript: они передаются строками без округления.

## Посты и premium emoji

- Нажмите эмодзи в каталоге, чтобы вставить его в текст.
- Для кнопки укажите ID в поле «Emoji ID»; это поле предлагает сохранённые значения. Можно скопировать ID кнопкой «ID» возле эмодзи.
- При добавлении по ID Telegram проверяет его через `getCustomEmojiStickers` и возвращает корректный обычный заменитель.
- Простая вставка в textarea из буфера не гарантирует сохранения Telegram entities. Для готового поста используйте «Импортировать пост» в боте (или `/post`), перешлите исходное сообщение, затем нажмите «Загрузить сохранённый» в редакторе сайта. Сохраняются текст, основные виды форматирования, custom emoji и одно фото. Существующий черновик заменяется; альбомы и исходные inline-кнопки автоматически не импортируются.
- Текст, кнопки, ссылки/file_id фото и флаги публикации автоматически сохраняются после редактирования; есть явная кнопка «Сохранить черновик». Перед публикацией черновик также сохраняется. Файлы фото, выбранные с устройства, после перезагрузки нужно выбрать заново.
- Каждый администратор имеет свой черновик; каталог эмодзи общий для администраторов.
- Кнопки отправляются и у постов с фото без подписи.
- Если в ответе Telegram отсутствуют запрошенные custom emoji / иконки кнопок, редактор показывает предупреждение после публикации. Это предупреждение не удаляет уже опубликованный пост.

**Ограничение Telegram:** Premium владельца разрешает боту использовать custom emoji в личных чатах, группах и супергруппах. Для канала официальная документация требует дополнительное имя бота, приобретённое через Fragment. Сохранить ID в базе можно независимо от прав, но код не может гарантировать постоянное отображение premium emoji при изменении прав Telegram. Обычный символ в каталоге сайта — заменитель для выбора, не предпросмотр premium-анимации.

Официальная документация: https://core.telegram.org/bots/api#html-style и https://core.telegram.org/bots/api#inlinekeyboardbutton

## Проверка

Серверные тесты: `python -m unittest discover -s tests -v` (тестовая SQLite во временном каталоге; запросы отправки в Telegram подменены). Проверены права администраторов, UTF-16 смещения и вложенные entities, сохранение приветствия, черновики и каталог, webhook `/start`, определение ID, импорт, фото без подписи с кнопками, диагностика отсутствующих emoji.

Реальная отправка в ваш Telegram-канал и работа TON-кошелька требуют проверки на вашем хостинге с его настройками. Тесты не отправляют сообщения и не выполняют платежи.

Браузерная проверка: ширины 320, 375, 390 и 1440 px; переходы между основными страницами без ошибок JavaScript и горизонтального переполнения; сохранение приветствия и восстановление черновика с emoji ID на кнопке после перезагрузки. Окна бонусов и игрока проверены визуально.
