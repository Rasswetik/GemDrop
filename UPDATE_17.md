# GemDrop — Update 17

Эта сборка основана на `GemDrop_Bonuses_Upgrade_Updated_15(3)` и сохраняет её структуру/визуальную основу.

## Что изменено

- Обновлён визуальный слой GemDrop без переноса спорного полного редизайна из версии 16.
- Переработаны список пользователей и окно профиля игрока в админ-панели.
- Унифицированы карточки, модальные окна, формы, кнопки, нижняя навигация и SVG-иконки.
- В админ-панель добавлен раздел **Настройки бота** с редактируемым приветствием `/start`.
- Для администраторов в `/start` добавлены **Определить ID эмодзи** и **Импортировать пост**.
- Бот умеет получать Telegram custom emoji ID из premium emoji, сохранять их в БД и показывать кнопку **Определить ещё**.
- Каталог сохранённых premium emoji доступен в редакторе публикаций.
- ID custom emoji хранятся строками, поэтому большие Telegram ID не теряют точность в браузере.
- Добавлено сохранение/восстановление черновика публикации для каждого администратора.
- Импорт сообщения через бота сохраняет Telegram entities/форматирование и custom emoji ID в черновик.
- Custom emoji можно использовать не только в тексте, но и в нижних inline-кнопках публикации через `icon_custom_emoji_id`.
- При публикации emoji из текста и кнопок повторно попадают в постоянный каталог.

## Важно для сохранности

Emoji, приветствие и черновики сохраняются в общей БД через `app_documents`. Если проект работает на SQLite на хостинге, `DATA_DIR` должен находиться на постоянном диске. Альтернатива — постоянный `DATABASE_URL` (PostgreSQL). Без постоянной БД любой хостинг с эфемерной файловой системой может удалить данные после redeploy/restart.

## Как определить ID premium emoji

1. Администратор пишет боту `/start`.
2. Нажимает **Определить ID эмодзи**.
3. Отправляет premium emoji или сообщение с несколькими premium emoji.
4. Бот возвращает точные ID и сохраняет их в каталог сайта.
5. Кнопка **Определить ещё** оставляет сценарий удобным для следующего emoji.

Для переноса уже готового Telegram-поста с premium emoji используйте **Импортировать пост**, затем в админке откройте **Публикации → Загрузить сохранённый**.
