Original Telegram gift animations bundled on 2026-10-13 from
https://cdn.changes.tg/gifts/originals/<telegram-gift-id>/Original.tgs.

`id-to-name.json` maps the 123 collections to their Telegram IDs.
`originals.zip` contains the 123 TGS files named by Telegram gift ID. Each TGS
was decoded and checked for a nonempty animation before inclusion.
The gift animation API uses these originals for collection gifts and uses the
exact model or NFT animation for specifically selected models or numbered NFTs.
It never replaces an unavailable animation with another model.

Lottie Web 5.12.2 is bundled in `../vendor` with its MIT license.
