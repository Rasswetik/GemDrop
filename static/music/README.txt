Музыка к медалям. Имя файла = ключ медали.
  kashtan.mp3  / kashtan_short.mp3   — Миша Каштан
  jealous.mp3  / jealous_short.mp3   — Jealous
  warhol.mp3   / warhol_short.mp3    — Andy Warhol
Длинная версия играет в профиле игрока. Короткая — при просмотре медали и при победе в PvP.

Любая медаль может иметь музыку: положите static/music/<ключ_медали>.mp3 (длинная, для профиля)
и static/music/<ключ_медали>_short.mp3 (короткая, для клика и победы). Ключ медали виден в админке
в каталоге медалей. Список подхватывается автоматически.
