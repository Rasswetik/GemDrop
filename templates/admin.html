CryptoBot / Crypto Pay

В своём @CryptoBot откройте Crypto Pay → Create App. Укажите название GemDrop и своего бота. Вставьте API token приложения ниже: платежи поступают на баланс этого приложения в вашем CryptoBot.

В Crypto Pay → My Apps → ваше приложение → Webhooks включите webhook и добавьте этот HTTPS URL. Проверка оплаты кнопкой работает и без webhook. Назначение счёта — пополнение GemDrop в TON; после оплаты кнопка ведёт к вашему боту.
